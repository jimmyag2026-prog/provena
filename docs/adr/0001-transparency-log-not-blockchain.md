# ADR 0001: 透明日志（RFC 9162 Merkle log）而非自建区块链

- Status: accepted · 2026-10-31

## Context
「ledger」需要：只追加、改写可检测、第三方可验证、时间可信。候选：自建链/联盟链、公链直接写入、透明日志（CT/Sigstore Rekor 模式）。

## Decision
每个项目一条 RFC 9162 Merkle 日志，由 Hub 排序并签发树头；见证人联署 + 周期性把「根之根」锚定到外部时间源（RFC 3161；OpenTimestamps 尚未实现）。

## Consequences
- 写入延迟毫秒级、零 gas、无代币；一个锚覆盖全部项目，成本与规模无关。
- 去信任程度来自：一致性证明（防改写）+ 见证人（防分叉视图）+ 外部锚（防倒签）。Hub 作恶可被检测但不能被阻止（可用性除外）——与 CT 同一安全模型，经过 10 年互联网规模验证。
- 需要实现见证人协议与锚定 worker（M8）。
