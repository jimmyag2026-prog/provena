# Provena v0.2.1 — release notes (2026-11-01)

A small follow-up to 0.2.0. The full list is the `[0.2.1]` section of `CHANGELOG.md`.

## What changed

- **Install name**: the PyPI distribution is **`provena-ledger`** (`pip install "provena-ledger[client]"`).
  The name `provena` on PyPI is an unrelated project. The import package and the `provena`
  command are unchanged, so existing checkouts, scripts and MCP configurations keep working.
- **Hub catalog unlisting**: an operator can take rehearsal or test projects off a hub's front
  page (`hub serve --unlisted FILE` or `PROVENA_HUB_UNLISTED_PROJECTS`). Nothing is deleted: the
  ledger is append-only, every unlisted project still answers by id with its proofs, the witness
  keeps cosigning it, and the page counts it ("N private and M unlisted project(s)").
- **Docs made consistent** with the repository (licence, witness status, fixed P0 findings,
  `rerun --sandbox` default, capture assurance levels), plus `SECURITY.md` and `CONTRIBUTING.md`.

## Upgrade

`pip install -U "provena-ledger[client]"` (or `[client,server]` for a hub). No ledger, bundle or
hub API format changes; 0.2.0 clients and hubs interoperate.
